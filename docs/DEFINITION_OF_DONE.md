# Definition of Done

A feature is not complete until the relevant items below are satisfied.

## Product
- objective achieved
- acceptance criteria met
- behavior matches project scope

## Engineering
- implementation complete
- code readable
- types/static checks pass
- migration handled
- errors actionable
- no dead/debug code

## Testing
- unit tests
- negative tests
- integration tests where needed
- security tests where needed
- regression tests for bugs

## Security
- input validated
- least privilege preserved
- secrets safe
- auth/authz correct
- auditability preserved
- failure mode reviewed
- threat model considered

## Observability
- useful logs
- relevant metrics
- traceability where needed
- no secret leakage

## Documentation
- user/dev docs updated
- public API changes documented
- security behavior documented
- ADR created if major decision

## AI-generated implementation
- code understood by human owner
- no unverifiable claims
- no copied incompatible code/license
- tests are independent enough to catch mistakes

## Merge
- CI green
- required review complete
- no unresolved high-severity concern
