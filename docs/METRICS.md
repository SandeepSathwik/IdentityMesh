# Project and Product Metrics

## Purpose
Track whether IdentityMesh is becoming useful and reliable.

## Engineering metrics
- test pass rate
- flaky test count
- critical-code coverage
- build duration
- release frequency
- open critical bugs
- dependency vulnerabilities

## Collector metrics
- collection success rate
- partial-access rate
- entities discovered
- collection duration
- provider errors

## Graph metrics
- node count
- edge count
- ingest duration
- path query duration
- duplicate path suppression

## Security metrics
- findings by severity
- validated true-positive rate in labs
- false positives in golden scenarios
- attack scenarios detected
- attacks prevented
- authorization decision latency
- deny/approval rate
- policy evaluation failures

## Documentation metrics
- clean setup success
- demo reproducibility
- issue-to-doc linkage for major features

## Portfolio metrics
Not product metrics, but useful:
- meaningful releases
- architecture write-ups
- research notes
- demo videos
- external contributors/issues
- benchmark reports

Avoid optimizing for raw commit count.
